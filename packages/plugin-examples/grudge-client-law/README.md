# Grudge client law

A Skill the studio agent loads before it picks a free library, a model, a
pipeline export, a GitHub repo, or a Puter modeling app.

An [OhMyGame](https://github.com/WhiteTowerAI/ohmygame) plugin, `grudge/client-law`,
on the [ohmygrudge](https://github.com/MolochDaGod/ohmygrudge) fork. It adds a
skill only. It does not add an engine, a bag, or a domain.

The law is `skills/grudge-client-law/SKILL.md`.

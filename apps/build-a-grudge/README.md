# Build a Grudge

Grudge Studio's client app. It replaces the Puter "Grudge Forge" draft.

Live: https://build.grudge-studio.com

Sign in is Grudge ID (`id.grudge-studio.com`, `app=build-a-grudge`). ALE speaks on this page. The chat host is `build-agent.grudge-studio.com`, the same Cloudflare agent reached through the `grudge_warlords` tunnel. Games you can play here are the authored starters, run in a sandboxed frame. The 3D world, deploy, and publish stay at https://builder.grudge-studio.com.

Player bags are not stored here.

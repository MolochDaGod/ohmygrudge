# Build a Grudge

Grudge Studio's client app. It replaces the Puter "Grudge Forge" draft.

Live: https://build.grudge-studio.com

Sign in is Grudge ID (`id.grudge-studio.com`, `app=build-a-grudge`). The page is one room: a sentence, ALE, and the game. The chat host is `build-agent.grudge-studio.com`. Games you can play here are the authored starters, run in a sandboxed frame. Walking a 3D world stays at https://builder.grudge-studio.com.

Player bags are not stored here.
